    Quản lý code tên Không bắt buộc

    Nhập ID và tên game, kiểm tra đúng định dạng rồi gửi danh sách về BTC. Dữ liệu giữ nguyên cách viết bạn đã nhập.

    Hướng dẫn nhập code tên
    1. Kiểm tra custom ở Bước 1. Custom đã được chọn sẵn theo khung giờ và bảng bạn đăng ký.
    2. Ở Bước 2, nhập ID game và tên game của từng người chơi, đúng như trong game.
    3. Xem trạng thái từng dòng. Dòng đúng định dạng sẽ hiện "Hợp lệ".
    4. Bấm "Lưu code tên", rồi "Sao chép danh sách gửi BTC" và gửi cho BTC trước hạn đổi code tên.
